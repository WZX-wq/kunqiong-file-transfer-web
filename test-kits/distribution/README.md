# 批量分发测试文件

## 规则

- 文件名使用 `编号__原文件名.ext`，例如 `001__alice.txt`。
- 名单每行使用 `编号,收件人`，收件人填写已验证登录账号的账号 ID、用户名、邮箱或手机号。
- 先点击“预览匹配”；问题清单为空后才能点击“确认发布”。

## 正常用例

选择 `files/001__alice.txt` 和 `files/002__bob.txt`，名单使用 `roster-valid.csv`。

预期：匹配 2 条，发布成功；管理员看到两个文件，alice 只能看到 `001__alice.txt`，bob 只能看到 `002__bob.txt`。

## 异常用例

- `roster-duplicate.csv`：同一编号出现两次，预览必须阻止发布。
- `roster-missing.csv`：名单中的编号没有文件，预览必须阻止发布。
- 把 `files/003__unmatched.txt` 一起选择但仍使用正常名单，预览必须提示文件没有对应收件人。
- 把分享链接发给未授权账号，访问必须返回无权提示，不能看到文件列表。
