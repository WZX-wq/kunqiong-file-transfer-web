# 我的订单

“我的订单”属于个人中心的设置栏目，沿用现有浅色、绿色点缀和简洁布局。

- 地址 `/settings/orders`。左侧「文件清理」下方增加与其他栏目一致的「我的订单」按钮，点击只在右侧显示订单信息，保留用户信息卡、侧栏和设置页的返回按钮。首页头像菜单和会员空间入口也进入此栏目；旧 `/orders` 地址兼容转到个人中心。
- 仅展示当前登录账号的套餐订单。按全部、待支付、已支付、已取消、已过期筛选，支持本站或支付平台订单号搜索，服务端分页，每页 5 条。
- 桌面为紧凑列表，手机为卡片。显示套餐、金额、状态、创建时间和详情操作，避免订单越多页面越长。
- 详情显示本站订单号、支付平台订单号、支付方式、支付确认时间和本单有效期，支持复制订单号。支付时间采用本站实际掌握的“确认时间”，不冒充支付平台扣款时间；历史有效期不等同于当前账户权益。
- 待支付订单可以继续原订单支付或在确认后取消；已取消、已过期且有支付平台订单号的订单仍可以核对付款结果。核对由服务端查询支付平台，前台不能直接授予权益。
- 订单列表和详情均为只读查询；主动核对使用 POST。列表仅返回展示字段，不返回收银台 HTML 或查询凭证。详情和修改接口每次检查订单归属，其他账号收到 404。
- 筛选、搜索和页码保存在 URL，支持刷新及浏览器前后退。加载失败保留操作入口并提供重试，登录失效清空订单，过时请求不得覆盖新筛选结果。

验证：真实接口测试覆盖分页、搜索边界、所有权和凭证脱敏；真实 React 页面测试覆盖筛选、搜索、详情、原订单继续支付、取消确认、核对结果、异常与登录失效。现有支付测试和构建回归。本次仅在本机实现和验证，不包含提交或部署。
