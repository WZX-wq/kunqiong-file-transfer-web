# 企业管理权限修复验证

执行日期：2026-10-13

本次修复覆盖企业团队权限审计中发现的隐私泄露、资源越权、成员撤权竞态和独立管理员角色缺失问题。测试均使用一次性隔离副本、合成账号和本机扫描协议模拟器，不操作真实账号、真实团队或业务文件。

## 权限规则

| 角色 | 允许操作 |
| --- | --- |
| 所有者 | 任免管理员、邀请和审批、管理全部团队文件、改名、转让所有权、解散团队 |
| 管理员 | 邀请和搜索、审批申请、移除普通成员、管理团队文件；不能移除管理员/所有者、任免角色、改名、转让或解散 |
| 普通成员 | 访问团队空间；管理自己仍归属团队的文件；不能查看待邀请凭证，其他成员联系方式脱敏 |

服务端每次根据当前有效成员关系和角色授权，不信任客户端角色、旧管理权限或上传者字段。管理员角色保存在元数据中，重启后仍有效；任命管理员不会提升其个人套餐，只增加团队侧管理能力。

## 修复范围

- 成员列表和用量列表按访问者脱敏，移除邀请 ID、申请 ID 和邀请内容等管理凭证。
- 团队所有者和管理员可管理团队文件；管理预览、单文件下载和整包下载绕过公开链接的关闭、密码和次数限制，但仍强制文件扫描。
- 管理下载和公开访问在异步扫描完成后再次校验成员、角色和资源存在性，扫描期间撤权不会返回文件。
- 个人收发记录清理不会物理删除团队资源；移除成员、撤销管理员和完成上传竞态均即时失效。
- 增加所有者专属的管理员任免接口和界面；管理员不能执行所有权操作。
- 禁止禁用账号或不存在账号被任命、接管；角色请求严格限制为 `admin`/`member` 且拒绝多余字段和错误结构。
- 团队文件管理下载使用独立管理接口，跨团队、游客和个人资源越权均拒绝。
