# 边界值修复与本地验证（2026-10-12）

本轮已对[原审计](边界值全量排查-2026-10-12.md)中的 BND-001–031 实施修复，并补充头像解码并发、嵌套记录、验证码类型、历史上传会话、收件人别名和 5 位取件码兼容性回归。以下结果对应当前本地工作区，包含原有未提交改动；尚未提交、推送或部署。

写接口采用严格校验，非法输入返回明确错误，避免静默截断、默认放宽或部分保存。历史存储读取仍保留容错，读取已有数据不会因新增输入规则整体失败。

## 明确采用的规则

| 契约 | 本轮实现 |
| --- | --- |
| RULE-001 | 维持单文件大小限制，页面统一显示“单文件上限”；单次及累计用量另由账号/团队容量校验。 |
| RULE-002 | 创建会话即返回最终 chunkSize，客户端采用协商值；明确提供时须正整数，收敛到 1–16 MB。 |
| RULE-003 | 下载次数按成功完成的 HTTP 下载请求计，Range 206 也计一次；HEAD、失败和断连不计。未引入逻辑下载票据。 |
| RULE-004 | 验证码证明目标联系方式持有权，不新增发起会话绑定；绑定唯一性与错误次数/TTL/重放规则保留。 |
| RULE-005 | 每次上传会话请求都校验 12 小时 TTL，不依赖定时清理宽限。 |
| RULE-006 | 支付方式只允许 1/2；外部期限必须真实可解析且不过业务上界，套餐天数 1–3650，非法响应不得激活。 |

长度按 HTML maxLength 一致的 UTF-16 单位计量。文件名另限 UTF-8 240 字节，相对路径限 1024 字节及 20 层；同批路径按大小写不敏感去重。需要改名的异常文件由用户修正，不自动改写名称。

## 验证范围和限制

这些结果证明本机覆盖场景通过，不能外推为所有真实环境都已验收。原生浏览器的 Worker/DecompressionStream、真实 OAuth/邮件/短信/支付、手机键盘与浏览器兼容性尚待环境验证。没有实际传输 5 GB 边界文件。

下载预占针对当前单 Node 进程；多实例共享存储仍需要跨进程原子配额。联系人绑定唯一性也是当前写入路径内的同步检查，分布式唯一约束未新增。Office PPTX 的最终绘制仍使用主线程库，已采用更小的输入、展开、XML、页数和图片预算；未声称绘制过程可被 Worker 强制中断。

构建保留已有 viewer 大包提示。头像新增 `sharp` 原生依赖，Node 需满足其 >=20.9 要求；本机安装和解码已验证，服务器镜像尚未构建或部署。历史畸形上传会话可能需要重新选择文件；严格校验不会自动修复历史文件名。
