## 预览能力检查与补齐（预览 vs 上传范围核对）

**核对结论**：图片/视频/音频/PDF/docx/xlsx/xls/csv/pptx 原本已支持预览；缺口如下，均已修复：

1. **文本/代码文件预览（新增 text 预览类型）**
   - server.mjs：`previewKind()` 新增 `text` 分支（`TEXT_PREVIEW_EXTENSIONS` 集合：txt/md/log/json/xml/yml/yaml/ini/conf/js/jsx/ts/tsx/html/htm/css/vue/swift/kt/java/py/go/php/rb/rs/c/cpp/h/cs/sh/ps1/bat/cmd/sql + 任意 `text/*` MIME）
   - `sendPreviewFile()`：text 类型强制 `Content-Type: text/plain; charset=utf-8`（关键安全点：防止 .html/.xml 以 text/html inline 渲染造成 XSS）
   - main.jsx：前端 `previewKind()` 同步加 text 分支；新增 `TextPreview` 组件（fetch → TextDecoder → `<pre>` 渲染，>512KB 截断并提示）；`previewTypeLabel`/`previewSupportLabel` 补 text 文案；styles.css 新增 `.text-preview-shell/.text-preview/.text-preview-truncated`
2. **SVG 前后端不一致修复**：前端此前把 svg 当 image 可预览，但后端 415 拒绝（防 SVG 内嵌脚本 XSS，正确行为）→ 前端已对齐：svg 不再显示预览按钮（mimeType 排除 `image/svg+xml` + 扩展名列表去掉 svg）
3. **表格预览多 Sheet 切换修复**：`.spreadsheet-tabs` 的 span 原本没绑 onClick，多工作表只能看第一个 → 加 setState 切换 + activeSheet 状态初始化/重置；样式加 cursor:pointer

**保持不预览（合理限制）**：avi/mkv/flv/wmv/wma（浏览器无法原生解码）、doc/ppt/rtf（纯前端无可靠解析器）、heic/heif（仅 Safari 支持）、svg（安全）。这些文件预览按钮不出现，仅可下载。

**验证**：node --check server.mjs ✓；npm run build ✓（10.66s）；本地起服 8097 端口冒烟：上传 js+csv → js 预览返回 `x-preview-type=text` + `text/plain; charset=utf-8`，csv 返回 `spreadsheet` ✓；测试 share 已通过 manage API 关闭并清理物理文件。

**修改文件**：server.mjs（previewKind/sendPreviewFile）、src/main.jsx（previewKind/标签/renderPreviewContent/TextPreview/OfficePreview sheet 切换）、src/styles.css（3 个新类）
