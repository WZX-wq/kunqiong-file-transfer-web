## 追加：前端 UI 细节优化（字色对比度 + 图标 + 设计感）

### 1. 文字对比度：411 条规则全部 ≥ 4.5:1
- 审计出**181 种**前景色不达标（最浅 `#b6c3bf` 仅 **1.82:1**）。
- ⚠️ **关键坑：必须做「双阈值」变暗**，不能只对「自身背景」达标：
  同一色值常在多处复用，某处落在淡彩底（如 `#e6f4ef`）、另一处落在白底。
  只按彩底算会一路压到 **#000**（第一版 45 色全变纯黑，已 `git checkout` 回滚）。
  → 正确判据 `ok(c,bg) = cr(c,bg) >= 4.55 && cr(c,'#fff') >= 4.3`。
- 算法：**保持 HSV 的 H（色相）与 S（饱和度）不变，只逐 0.004 降 V**，
  取第一个满足双阈值的值 → 色相与层级排序都保住（`#b6c3bf` → `#6f7674`，4.65:1）。
- `--muted` `#78908b`(3.35) → `#567570`(5.03)；`:root` 里只剩这一个 token 需要改。
