### 根因

### 修复

1. 项目内 `npm install jsdom --no-save`（用 managed node 的 npm-cli.js；注意 `node_modules/npm` 在项目里不存在，
   要写绝对路径 `C:/Users/admin/.workbuddy/binaries/node/versions/22.22.2-3/node_modules/npm/bin/npm-cli.js`）
2. esbuild 把 `src/main.jsx` bundle 成临时 esm（`external: react/react-dom`，loader 处理 svg/css）
3. jsdom 造 DOM + `Object.defineProperty(global,'navigator',...)`（Node 22 navigator 是只读 getter，
   直接赋值会 TypeError）；mock `fetch` 返回 `/api/auth/me` 与 `/api/account/team/overview`
4. import bundle 后读 `document.getElementById('root').innerHTML`，并收集 window.error / console.error

**实测对比（证明诊断准确）**：

- 保留该行：完整渲染（成员使用量、3 个 tab 都在），无 ReferenceError
